## Selected work

| | What it is | Stack |
|---|---|---|
| **Live video notarization** | Multi-party real-time video sessions where every participant signs the same document together. Core to BlueNotary's product and the piece the entire signing flow depends on. | WebRTC · Node.js · Vue.js · Redis |
| **Search across 2B documents** | Free-text search over roughly two billion text blobs. Index design, query shaping and relevance tuning to keep response times usable at that scale. | Elasticsearch · Python · Sharding |
| **10× ingestion pipeline** | A reworked framework for consuming large volumes of public-source data that cut processing time by an order of magnitude, feeding 100+ resilient scrapers. | Python · Celery · RabbitMQ |
| **BlueBricks site builder** | A block-based no-code builder that lets a non-technical user assemble and publish a full website in minutes. | Vue.js · Node.js · MongoDB · S3 |
| **Client onboarding framework** | Took enterprise deployment time from 15 days down to 3. | Python · Node.js · Linux |

A few numbers I am fond of: API responses from **3–4s to 200ms** through layered caching.
Ingestion **10× faster**. Onboarding **5× faster**. **10 engineers** mentored at peak.
